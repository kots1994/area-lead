FAQ

よくあるご質問

Google Maps API のキーは自分で用意するの？
いいえ、AreaLead 側で管理しています。あなたは課金プランの範囲内で生成回数のみ気にすればOKです。Enterpriseプランでは持ち込みのAPIキーも利用可能です。
スクレイピングは合法？
公開Webページの非商用閲覧と同等の挙動で、各社のrobots.txtを尊重し、レート制限を厳格に守ります。取得するのは公開メタ情報・公開メアド・問合せフォームURLに限定。SNS投稿・会員専用ページ等は対象外。
取得したリストの使い方は？
CSVをダウンロードして既存CRMに取り込んだり、姉妹サービスの「サクッと営業フォーム」拡張機能と組み合わせて即フォーム送信できます。Pro プランで Slack/Sheets 連携も準備中。
1回で取れる件数は？
Google Places API の制約で1検索 = 最大20件。ただしエリアやキーワードを変えて連続検索することで実質無制限に拡張できます。Proプランでは月10,000行まで。
個人情報の取扱いは？
取得した企業情報・連絡先はサーバー側で保存しません。検索ごとに揮発します。利用ログは最低限のメタ情報（リクエスト件数等）のみ保持。
解約はいつでもできる？
はい。Stripe のカスタマーポータルから1クリックで停止できます。日割計算で返金。
